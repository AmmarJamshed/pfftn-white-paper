# Glossary

| Term | Meaning |
| --- | --- |
| AML/CFT | Anti-Money Laundering / Combating the Financing of Terrorism |
| CDD | Customer Due Diligence |
| DLT | Distributed Ledger Technology |
| EDD | Enhanced Due Diligence |
| EMI | Electronic Money Institution |
| KYC | Know Your Customer |
| MFI (this paper) | Merchant Financial Identity (not microfinance institution) |
| PFFTN | Pakistan Federated Financial Trust Network (proposed) |
| PSO / PSP | Payment System Operator / Payment Service Provider |
| Raast | Pakistan’s instant payment system |
| Raast P2M | Person-to-Merchant acceptance (QR, Alias, IBAN, RTP) |
| Verifiable credential | Digital proof that a fact was verified by an issuer |
